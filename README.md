# Senai-Cardapio-React

Cardápio Digital — React (Aula 08)

## Descrição

Aplicação React desenvolvida com JSX, componentes, props, listas e renderização condicional, conforme proposto na Aula 08. Permite filtrar pratos por categoria e adicionar itens ao carrinho.

## Tecnologias

- React 18
- HTML5
- CSS3
- JavaScript

## Conceitos aplicados (Aula 08)

- JSX e expressões JavaScript
- Componentes funcionais e composição
- Props (passagem de dados entre componentes)
- Listas e Keys (map() para renderizar pratos)
- Renderização condicional
- Estado com useState

## Como executar

Abra o arquivo `index.html` em qualquer navegador moderno.
